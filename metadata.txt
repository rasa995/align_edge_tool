description=Interactive editing tool: Edge Aligner moves an edge onto a reference boundary.
about=One click on an edge aligns the stretch of that edge lying within a tolerance of the nearest reference boundary (polygon or line layers, same or other layer). In "selected features" mode, a click on a reference boundary aligns all selected features to it. Features in layers in edit mode that share the moved stretch are moved too, so shared boundaries stay identical. While hovering, the stretch that will move, its target and the area in between are shown, with an info box at the cursor saying what the click will do (or why it would be refused); Tab picks another nearby reference. "Align all within tolerance" scans the layers in edit mode for every stretch close to a base layer, lists them for review and aligns them all. Z/M values are kept, straight geometries in curve layers are supported, and reference layers may use another CRS. All settings are in a drop-down menu on the tool button. Before writing, every change is checked for invalid geometries, fold-backs, and new gaps or overlaps within a layer. Uses only QGIS core functionality; every change is one undoable edit command per layer.
